# Decisions that shape Receipts

A one-page index of the decisions that most shape the product, newest first.
Each line gives the decision, what it cost, and a link to the full entry in
[`RECONCILIATION.md`](RECONCILIATION.md), an ADR or the PR. When this page and
the linked entry disagree, the entry wins.

Entries from 2026-10-11 onward were reconstructed on 2026-10-17 from PR
descriptions and commit messages (see
[the note](RECONCILIATION.md#2026-10-17--what-follows-is-reconstructed)).
